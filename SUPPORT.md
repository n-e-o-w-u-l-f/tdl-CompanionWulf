# Support

Before opening an issue:

1. run `tdl-companionwulf doctor`
2. confirm `tdl` works independently
3. reproduce with `--dry-run` when the problem concerns command construction
4. record your operating system, Python version and CompanionWulf version
5. remove usernames, chat IDs, tokens and session paths that are not required to reproduce the problem

Use the bug template for defects and the feature template for enhancement requests. For Sidecart migration questions, consult [PARITY.md](PARITY.md) and [MIGRATION.md](MIGRATION.md).
