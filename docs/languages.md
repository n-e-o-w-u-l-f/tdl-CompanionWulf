# Languages

CompanionWulf normalizes the locale families `de`, `en`, `fr`, `es`, `it`, `pt`, `nl`, `pl`, `cs`, `sk`, `hu`, `ro`, `tr`, `ru`, `uk`, `bg`, `el`, `sv`, `da`, `no`/`nb`/`nn`, and `fi`.

Use automatic detection or override it:

```text
tdl-companionwulf config set language auto
tdl-companionwulf wizard --language de
```

README translations are indexed in [../README.TRANSLATIONS.md](../README.TRANSLATIONS.md). Runtime UI text falls back to English when no explicit localized legacy string exists.
