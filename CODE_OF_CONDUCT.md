# Code of Conduct

Project discussions should remain technical, respectful and relevant to the work.

- critique code and behavior, not people
- provide reproducible evidence for bug claims when possible
- do not publish another person's credentials, private chat data or identifying session material
- avoid harassment, threats and discriminatory abuse
- maintainers may remove content or participation that materially disrupts the project or exposes sensitive information

Questions about a moderation decision should be raised privately with the repository owner where possible.
